📚 Projetos em Java – Exercícios Práticos

Este repositório reúne atividades propostas pelo professor, organizadas em duas listas de exercícios implementadas em **Java**, com foco na prática de conceitos fundamentais da linguagem, como:

* Estruturas de repetição (`for`, `while`)
* Estruturas condicionais (`if/else`)
* Vetores (arrays)
* Entrada de dados com `Scanner`
* Operações matemáticas básicas
* Manipulação de caracteres (`char`)

Cada classe representa um problema prático resolvido de forma independente.

---

🛠️ Requisitos

* Java JDK 8 ou superior
* IDE de sua preferência (IntelliJ IDEA, VS Code, Eclipse, etc.)

---

---

📌 Projetos

1. 📊 `notasAlunos.Notas`

Realiza a análise de desempenho de uma turma com base em um conjunto de notas armazenadas em um vetor.

Funcionalidades:

* Calcula a média geral das notas
* Conta quantos alunos obtiveram nota maior ou igual à média
* Identifica a maior nota do conjunto

Saída esperada:

* Média da turma
* Quantidade de alunos acima da média
* Maior nota registrada

---

 2. 💵 `conversorDeNotas.NotasDinheiro`

Efetua a conversão de um valor inteiro em cédulas disponíveis (R$50, R$20 e R$10).

Funcionalidades:

* Recebe um valor inteiro informado pelo usuário
* Calcula a quantidade mínima de cédulas de 50, 20 e 10 necessárias

Aplicação prática:

* Simulação de caixas eletrônicos (ATM)

---

3. 🔐 `ValidaçaodeSenha`

Valida uma senha informada pelo usuário com base em critérios mínimos de segurança.

Critérios de validação:

* A senha deve possuir pelo menos 8 caracteres
* Deve conter ao menos um caractere especial (não alfanumérico)

Funcionalidades:

* Leitura da senha via teclado
* Verificação do tamanho
* Identificação de caracteres especiais utilizando a classe `Character`

---

4. ⏱️ `conversorSegundos.SegundospraHora`

Converte um valor em segundos para o formato de tempo equivalente em:

* Horas
* Minutos
* Segundos

Funcionalidades:

* Entrada de dados via teclado
* Conversão utilizando divisão e operador módulo

---

5. 🔢 `numeros.NumerosIguais`

Verifica se existem números repetidos em uma sequência de inteiros fornecida pelo usuário.

Funcionalidades:

* Armazenamento de até 200 números em um vetor
* Entrada contínua até que seja informada uma entrada inválida
* Comparação entre elementos para identificar repetições

**Saída:**

* Informa se há ou não elementos duplicados na lista
